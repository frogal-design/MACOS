## 2026-07-27 - [Supply Chain Surface Reduction & Direct Dependency Hardening]
**Vulnerability:** Global exposure of sensitive credentials (e.g. `GEMINI_API_KEY`) via Vite's `define` config and vulnerable dependencies (`react-router-dom`, `vite`) in the package manifest.
**Learning:** Vite's `define` property can globally replace environment variables and inadvertently leak secrets to the compiled client-side JavaScript bundle, even if they are not explicitly imported or used in the application's source code. Additionally, maintaining unused dependencies like `express` and `dotenv` in a static frontend codebase artificially inflates the supply chain attack surface and introduces noise during security audits.
**Prevention:** Avoid defining sensitive environment variables in `vite.config.ts`. Regularly audit the package manifest to ensure only strictly required dependencies are present, and immediately upgrade key routing and build tool versions to their secured, non-vulnerable target versions.
