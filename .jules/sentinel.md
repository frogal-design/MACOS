## 2026-08-07 - [Exposed Client-Side Defines & Supply Chain Surface Regression]
**Vulnerability:** A merge regression reintroduced a global client-side define block in `vite.config.ts` mapping the sensitive `process.env.GEMINI_API_KEY`, alongside insecure and unused server-side dependencies (`express`, `dotenv`, `@google/genai`, `@types/express`) and an outdated `react-router-dom` (which contained a high-severity CSRF vulnerability).
**Learning:** Merging older branches or automated generation tools can re-introduce legacy and insecure configuration files, leading to major security regressions like credential exposure in client-side bundles and package bloat. It is critical to continuously audit build configuration files and dependency configurations.
**Prevention:** Establish a strict static scan and automated dependency lock-in for Vite configuration files. Ensure that any client-side `define` block is audited to prevent the leakage of sensitive environment variables like `GEMINI_API_KEY`. Regularly run `pnpm audit` to capture outdated dependencies.
